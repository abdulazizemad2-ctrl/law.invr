# بنك أسئلة القانون التجاري — ملخصات أبو عماد

موقع تفاعلي لأسئلة الاختيار من متعدد في مقرر القانون التجاري (390 سؤالاً).

- أسئلة من تجميعات الاختبارات السابقة داخل حدود المقرر، وأسئلة جديدة بنفس صياغتها.
- اختيار الفصل والموضوع، ومصدر الأسئلة، وعدد الأسئلة.
- وضع تدريب بتصحيح فوري وشرح، ووضع محاكاة اختبار بنتيجة نهائية، ومؤقت اختياري.
- حفظ الأخطاء على جهاز الطالب لمراجعتها لاحقاً.

الموقع ملف واحد: `index.html`. لتشغيله على GitHub Pages: Settings ← Pages ← Deploy from a branch ← `main` / root.
